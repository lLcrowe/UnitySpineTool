# Unity Spine Tool

Spine 4.3의 기존 `SkeletonAnimation`·`SkeletonRenderer`를 그대로 사용하는 애니메이션 제어, IK, 이벤트 주입, 동기화와 에디터 도구를 제공하는 Unity 패키지입니다.

## 요구 사항

- Unity 6000.3 이상
- Spine C# Runtime 4.3.39
- Spine Unity Runtime 4.3.98

Spine Runtime 패키지를 먼저 설치한 뒤 `com.llcrowe.unity-spine-tool`을 추가하세요. Spine Unity 패키지가 감지되면 필요한 `SPINE_UNITY` 심볼이 자동 활성화됩니다.

자세한 기능과 사용법은 [SpineTool 가이드](SpineTool/README.md)를 참고하세요. VAT 기능은 이 패키지에 포함되지 않습니다.
