# Unity Spine Tool

Spine 4.3용 애니메이션 제어, IK, 이벤트 주입, 에디터 미리보기와 VAT 베이킹 도구를 제공하는 Unity 패키지입니다.

## 요구 사항

- Unity 6000.3 이상
- Spine C# Runtime 4.3.39
- Spine Unity Runtime 4.3.98

Spine Runtime 패키지를 먼저 설치한 뒤 `com.llcrowe.unity-spine-tool`을 추가하세요. Spine Unity 패키지가 감지되면 필요한 `SPINE_UNITY` 심볼이 자동 활성화됩니다.

자세한 기능과 사용법은 [SpineTool 가이드](SpineTool/README.md)와 [Spine VAT 가이드](Core/Modules/SpineVAT/README.md)를 참고하세요.
